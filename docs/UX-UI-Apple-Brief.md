# UX/UI Upgrade Brief — Apple-style pass

งานปรับหน้าตา ClinicWorks POS ให้เข้าใกล้ภาษาออกแบบของ Apple

*A work brief for bringing the POS closer to Apple's design language.*

ทุกตัวเลขในเอกสารนี้**วัดจากแอปจริง** ไม่ใช่ความเห็น — วัดที่หน้าจอ iPhone 390×844
บนชุดทดสอบ `pos/testrun/test2.html`

*Every number here was measured on the running app at 390×844, not guessed.*

## สรุปที่วัดได้ / What the measurement found

| วัดอะไร | ผลลัพธ์ | เกณฑ์ |

# 8 งาน เรียงตามผลกระทบ

## 1 · แท็บ 21 อัน → 5 + More  ⭐ ผลกระทบสูงสุด

**ตอนนี้:** `TABS` มี 21 รายการ แถบแท็บกว้าง 686px บนจอ 390px แปลว่า
**พนักงานต้องเลื่อนแถบแท็บเพื่อหาแท็บ** ป้ายชื่อแท็บเป็นตัวอักษร **8px**
เล็กกว่าเกณฑ์อ่านออกครึ่งหนึ่ง

**Apple ทำยังไง:** tab bar ≤ 5 ช่อง มีป้ายชื่อทุกช่อง ที่เหลือไปอยู่ใต้ "More"
ซึ่งเป็นรายการแบบ inset list เลื่อนลงอ่าน แท็บ**ไม่เคยเลื่อนซ้ายขวา**

**ทำอะไร:**
- เลือก 5 แท็บที่พนักงานหน้าร้านใช้จริงทุกกะ — เสนอ: `pos` · `inventory` · `crm` · `shift` · `more`
- ที่เหลือ 16 อันย้ายเข้าหน้า **More** เป็นรายการจัดกลุ่ม (การเงิน / จัดการ / เครื่องมือ)
- ป้ายชื่อแท็บขั้นต่ำ **11px** ช่องละกว้างเท่ากัน `flex:1`
- เดสก์ท็อปเก็บแท็บครบได้เหมือนเดิม — แยกเงื่อนไขที่ตัวแปร `mob` ที่มีอยู่แล้ว

**ที่ไหน:** `pos/app.fixed.jsx` — `const TABS=[...]` (~บรรทัด 4280) และ
`MORE_IDS` (~4491) ซึ่งมีแนวคิด "แท็บรอง" อยู่แล้ว แค่ยังไม่ได้ใช้กับ 16 อันนี้

**ตรวจว่าเสร็จ:** ที่ 390px `document.documentElement.scrollWidth` ต้องเท่ากับ
`window.innerWidth` ทุกแท็บ

## 2 · สร้างสเกลตัวอักษร แล้วบังคับใช้

**ตอนนี้:** ขนาดตัวอักษรที่ใช้บ่อยที่สุดคือ **10px** และมี **151 จุดที่เล็กกว่า 12px**
รวมทั้งชื่อสินค้าและป้ายแท็บ ซอร์สเขียน `fontSize:` ตรง ๆ **1,440 ครั้ง**
ไม่มีใครรู้ว่าขนาดไหนคือ "ปกติ"

**Apple ทำยังไง:** มี text style ที่ตั้งชื่อไว้ไม่กี่แบบ (Large Title, Title, Headline,
Body, Callout, Caption) ทุกหน้าจอเลือกจากรายการนี้ ไม่มีการพิมพ์ตัวเลขเอง
body บนมือถือ 17px

**ทำอะไร:** เพิ่ม token ข้าง ๆ `C` แล้วไล่แทนทีละหน้าจอ

```js
const T = {
  largeTitle: { fontSize: 28, fontWeight: 700, letterSpacing: -0.4 },
  title:      { fontSize: 22, fontWeight: 700, letterSpacing: -0.3 },
  headline:   { fontSize: 17, fontWeight: 600 },
  body:       { fontSize: 17, fontWeight: 400, lineHeight: 1.45 },
  callout:    { fontSize: 15, fontWeight: 400 },
  footnote:   { fontSize: 13, fontWeight: 400 },
  caption:    { fontSize: 12, fontWeight: 500, letterSpacing: 0.2 },
  mono:       { fontVariantNumeric: "tabular-nums" },
};
```

**กฎ:** ไม่มีอะไรต่ำกว่า **12px** ป้ายกำกับเล็กสุด 12px ตัวเลขเงินและจำนวน
ต้องมี `fontVariantNumeric:"tabular-nums"` เสมอ ไม่งั้นตัวเลขวิ่งตอนอัปเดต

**ทำทีละส่วน** ไม่ต้องแก้ 1,440 จุดในทีเดียว — ไล่ทีละแท็บ เริ่มที่ POS กับ Stock
ที่พนักงานอยู่นานที่สุด

## 3 · หน้า Finance: เลิกใช้สีเป็นของตกแต่ง

**ตอนนี้:** หน้า Finance มีปุ่ม 12 ปุ่ม เรียง 6 แถว แต่ละปุ่มคนละสี —
POs ฟ้า · EOD ส้ม · Webhook เทา · Cash Flow ฟ้า · Loans ส้ม · Target ส้ม ·
+ Expense เขียว · Scan Receipt เทาตัวหนังสือฟ้า
**สีไม่ได้แปลว่าอะไรเลย** ตาต้องอ่านทุกปุ่มเพราะสีไม่ช่วยจัดลำดับ
แถมหัวข้อ "Finance & P&L" ถูกบีบอยู่ข้างซ้ายให้ปุ่มไหลล้อมรอบ

**Apple ทำยังไง:** หนึ่งหน้าจอมี **CTA หลักสีเน้นได้อันเดียว** ที่เหลือเป็นปุ่มเรียบ
สีมีความหมายเสมอ — ฟ้า = ทำได้/ลิงก์, แดง = อันตราย, เขียว = สำเร็จ
งานที่มีเยอะ ๆ ใส่ไว้ใน **grouped inset list** แบบหน้า Settings ไม่ใช่ปุ่มลอย 12 ปุ่ม

**ทำอะไร:**
- หัวข้ออยู่บรรทัดของตัวเอง เต็มความกว้าง ใช้ `largeTitle`
- **+ Expense** เป็น CTA เดียวที่มีสีพื้น (เขียวมิ้นต์) — เป็นสิ่งที่กดบ่อยที่สุด
- อีก 11 อันเป็นรายการแบบ inset list จัดกลุ่ม: *รายงาน* (EOD, VAT, Break-Even, Cash Flow) ·
  *เจ้าหนี้/เจ้าของ* (POs, Suppliers, Loans, Target) · *เชื่อมต่อ* (Webhook, Email, Scan Receipt)
- สวิตช์ VAT/Excise ย้ายไปอยู่กลุ่มของตัวเองพร้อมป้ายกำกับ ไม่ปนกับปุ่ม

**ที่ไหน:** ส่วน Finance ใน `app.fixed.jsx` — หาด้วย `grep -n '"finance"' pos/app.fixed.jsx`

## 4 · แถวเลื่อนซ้ายขวา 4 ชั้นบนหน้าขาย

**ตอนนี้:** ก่อนจะเห็นสินค้าชิ้นแรก พนักงานเจอแถบเลื่อนแนวนอน **4 ชั้นซ้อนกัน** —
ปุ่มลัด (Checklist/Cash Count/Age ID/Tables/Currency/Happy Hr) → โต๊ะ (No Table/T1…Bar 1)
→ สาขา → หมวดสินค้า กินพื้นที่เกินครึ่งจอก่อนถึงของที่จะขาย

**Apple ทำยังไง:** ตัวกรองหลัก **หนึ่งแถว** เป็น segmented control ตัวกรองรอง
ซ่อนหลังปุ่ม Filter ที่เปิดเป็น sheet ขึ้นมา เนื้อหาสำคัญที่สุดอยู่บนสุดเสมอ

**ทำอะไร:**
- เก็บไว้บนจอเฉพาะ **หมวดสินค้า** แถวเดียว (แถวที่ใช้ทุกครั้งจริง ๆ)
- สาขา + โต๊ะ ย้ายขึ้นไปอยู่แถบบนเป็นตัวเลือกเล็ก ๆ — มันคือ *บริบทของกะ* ไม่ใช่ตัวกรองที่เปลี่ยนทุกบิล
- ปุ่มลัด 6 อัน ย้ายเข้า sheet ที่เปิดจากปุ่มเดียว หรือย้ายไปแท็บ Shift ซึ่งเป็นที่ของมัน
- **ผลที่ได้: สินค้าขึ้นสูงกว่าเดิมประมาณ 300px** = เห็นสินค้ามากขึ้น 1 แถวเต็มโดยไม่ต้องเลื่อน

## 5 · เลิกใช้อีโมจิเป็นไอคอน

**ตอนนี้:** ไอคอนทั้งแอปเป็นอีโมจิ — 🕐 🛒 💡 📊 📦 👥 💰 🧾 🌐 👤 📑 📋
นี่คือสัญญาณ "ไม่ใช่ Apple" ที่แรงที่สุด และมีปัญหาจริงด้วย:
อีโมจิหน้าตาไม่เหมือนกันข้ามเครื่อง (Android/Windows/iOS คนละชุด) น้ำหนักเส้นคุมไม่ได้
เปลี่ยนสีตามสถานะไม่ได้ และบางตัวเป็นภาพสีเต็มปนกับแบบแบน

**Apple ทำยังไง:** SF Symbols — ไอคอนเส้นชุดเดียว น้ำหนักเดียวกับตัวหนังสือข้าง ๆ
เปลี่ยนสีและน้ำหนักได้ ทึบเมื่อ active เส้นโปร่งเมื่อไม่ active

**ทำอะไร:** แทนที่ด้วย inline SVG เส้น stroke 1.5–2px ชุดเดียวกันทั้งแอป
(Lucide หรือ Heroicons outline ให้ผลใกล้เคียง SF Symbols มาก — ก๊อป path มาใส่ตรง ๆ
ไม่ต้องลง library เพราะแอปเป็นไฟล์เดียว)
เริ่มที่ **แถบแท็บ** ก่อน เห็นผลมากที่สุดและงานน้อยที่สุด

> อีโมจิบน**การ์ดสินค้า**ที่ยังไม่มีรูปให้เก็บไว้ได้ — อันนั้นเป็น placeholder ไม่ใช่ไอคอน
> และจะหายไปเองเมื่อรูปจริงมาครบ

## 6 · ปุ่ม 47 อันเล็กเกินนิ้ว

**ตอนนี้:** 47 เป้ากดเล็กกว่า 44×44 รวมถึงตัวเลือกสาขา (`36×19`, `90×19`)
สวิตช์ภาษา (`88×22`) และปุ่มไอคอน `🔄 🪪 ✅ ⏏` ที่ `34×25`
ร้านใช้บนแท็บเล็ต มือเปียก ใส่ถุงมือ — 19px คือกดพลาดแน่นอน

**Apple ทำยังไง:** ขั้นต่ำ 44×44pt **ไม่มีข้อยกเว้น** ถ้าอยากได้หน้าตาเล็ก
ให้พื้นที่กดใหญ่กว่าที่ตาเห็นได้ (padding โปร่งใส)

**ทำอะไร:**
```js
minHeight: 44, minWidth: 44,
display: "inline-flex", alignItems: "center", justifyContent: "center"
```
ใส่ที่ `gs.btn` / `gs.btnLg` / `gs.chip` แล้วมันจะไล่แก้ให้เองเป็นส่วนใหญ่
ปุ่มไอคอนล้วนต้องมี `aria-label` ด้วย — ตอนนี้ยังไม่มี คนใช้ screen reader ได้ยินแค่ "ปุ่ม"

## 7 · Toast และ popup ทับเนื้อหา

**ตอนนี้:** toast "StoreHub synced" ทับโลโก้และปุ่มกะทั้งแถว ส่วน popup
"สวัสดีค่ะ ฉันคือ Bryan AI" เด้งขึ้นมาเองทับกราฟ Revenue vs Target
จนอ่านการ์ด Break Even ไม่ได้

**Apple ทำยังไง:** ของแจ้งเตือนลงมาจากบนแบบ **ไม่ทับ** เนื้อหา (ดันเนื้อหาลง)
หรือลอยอยู่ล่างเหนือ tab bar สิ่งที่ผู้ใช้ไม่ได้ขอ **ไม่บังสิ่งที่ผู้ใช้กำลังอ่าน**
พื้นหลังใช้ material เบลอ ให้รู้ว่ามีอะไรอยู่ข้างหลัง

**ทำอะไร:**
- Toast ย้ายไปล่าง เหนือแถบแท็บ `bottom: calc(tabbar + 12px)` กว้างไม่เกิน `min(92vw, 420px)`
  หายเองใน 3 วินาที
- Popup ทักทาย AI ไม่ควรเด้งเอง — เปลี่ยนเป็น badge เล็กบนปุ่ม 🤖 แทน
  ถ้าจะเก็บไว้ ต้องเด้งครั้งเดียวตลอดชีพเครื่อง แล้วจำใน localStorage
- พื้นหลัง overlay ใช้ `backdrop-filter: blur(20px) saturate(1.6)` + พื้นโปร่ง
  แทนสีทึบ — ได้ความรู้สึก "material" แบบ iOS ทันที

## 8 · เก็บกวาดสเกล: มุมโค้ง ระยะห่าง เงา

**ตอนนี้:** มุมโค้ง **11 ค่า** (3, 5, 6, 7, 8, 9, 10, 11, 12, 16, 999)
ระยะห่างหลุดกริด (9px, 11px, 7px ปนกับ 8/12) เงา 5 แบบ

**Apple ทำยังไง:** ค่าน้อย ๆ ที่คงเส้นคงวา ความสม่ำเสมอนี่แหละที่ตาอ่านว่า "ประณีต"

**ทำอะไร:** เพิ่มลงข้าง `C` แล้วไล่แทน

```js
const R = { sm: 8, md: 12, lg: 16, xl: 22, pill: 999 };
const S = { 1: 4, 2: 8, 3: 12, 4: 16, 5: 24, 6: 32 };   // ทวีคูณของ 4 เท่านั้น
const E = {                                              // elevation
  card:  "0 1px 2px rgba(0,0,0,.30), 0 8px 24px -8px rgba(0,0,0,.45)",
  sheet: "0 -1px 0 rgba(255,255,255,.06) inset, 0 -12px 40px rgba(0,0,0,.55)",
};
```

# สิ่งที่**ห้าม**แตะ / Do not touch

สิ่งเหล่านี้ถูกต้องแล้ว การ "ปรับให้สวยขึ้น" จะทำให้แย่ลง

1. **พาเลตต์สีเขียวเข้ม** (`C.bg #090f0b` → `C.card3 #1d2a20`) — มันดีอยู่แล้ว
   ดำอมเขียวจริง ไม่ใช่เทากลาง งานนี้คือปรับ**สเกล** ไม่ใช่เปลี่ยน**สี**
2. **`inkOn(bg, fg)`** — มีอยู่เพราะเคยเจอชื่อสินค้าคอนทราสต์ 1.05:1 ของจริง
   ห้ามข้าม ห้ามใส่สีตรง ๆ แทน
3. **การ์ด KPI ในหน้า Finance** (แถบสีด้านซ้าย + ป้ายตัวพิมพ์ใหญ่ + ตัวเลขใหญ่) —
   นี่คือส่วนที่ใกล้ Apple ที่สุดในแอปอยู่แล้ว **เอาเป็นต้นแบบให้ส่วนอื่น**
4. **ปุ่มหมวดสินค้าแบบ pill สีมิ้นต์ตอน active** — ถูกต้องแล้ว
5. **ตัวเลขบนตาชั่ง** — `0.039` ต้องเป็น `0.039` ห้ามปัดเพื่อความสวย

- แก้ที่ **token** (`C`, `gs`, และ `T`/`R`/`S`/`E` ที่จะเพิ่ม) ห้ามใส่ hex ราย component
- ทดสอบ: build → เสิร์ฟผ่าน HTTP (ไม่ใช่ `file://`) → เดินทุกแท็บด้วย Playwright
  ต้อง **pageerror = 0**

**ตัวเลขที่ต้องวัดซ้ำหลังแก้แต่ละข้อ:**

```js
// รันใน console ที่หน้าจอกว้าง 390px
document.documentElement.scrollWidth === window.innerWidth   // ต้อง true
[...document.querySelectorAll('button,a,input,select')]
  .filter(e => { const r = e.getBoundingClientRect();
    return r.width && (r.height < 44 || r.width < 44); }).length   // เป้าหมาย 0
[...document.querySelectorAll('*')]
  .filter(e => !e.children.length && e.innerText?.trim()
    && parseFloat(getComputedStyle(e).fontSize) < 12).length       // เป้าหมาย 0
```
