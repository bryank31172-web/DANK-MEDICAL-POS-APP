# ส่งงานต่อให้ ChatGPT — สร้างรูปสินค้าสไตล์ BOTANICAL LEGENDS
### Handoff brief: generate the shop's product artwork

วิธีใช้: อัปโหลดไฟล์ในโฟลเดอร์นี้เข้า ChatGPT แล้ววางข้อความในหัวข้อ
**"คำสั่งที่ต้องวาง"** ด้านล่างทั้งบล็อก
*How to use: upload the files in this folder to ChatGPT, then paste the whole
block under **"THE PROMPT TO PASTE"**.*

| ไฟล์ | คืออะไร |
|---|---|
| `handoff/image-jobs.json` | **ไฟล์หลัก** — 41 รายการ พร้อม prompt สำเร็จรูปและชื่อไฟล์ที่ต้องใช้ |
| `products.json` | แคตตาล็อก 53 รายการ (id, ชื่อ, ราคา, รูปปัจจุบัน) |

## กติกาที่ห้ามพลาด / The rules that matter

**1. ใช้ prompt แบบ B เท่านั้นสำหรับรูปในแอป**
`promptB_artOnly` = จัตุรัส 1:1 **ไม่มีตัวหนังสือในรูป**
POS พิมพ์ชื่อกับราคาทับรูปอยู่แล้ว ถ้าใช้แบบ A ชื่อจะขึ้นสองรอบซ้อนกัน อ่านไม่ออก
`promptA_fullCard` (3:2 มีตัวหนังสือ) เก็บไว้ทำ IG / ป้ายเมนู / โปสเตอร์ — คนละงาน

**2. ชื่อไฟล์ต้องตรงกับช่อง `file` เป๊ะ ๆ**
`crunch-berrie.jpg`, `mac1.jpg`, `thai-orange-tea.jpg` …
ผิดตัวเดียวรูปจะไม่ขึ้น — สคริปต์จับคู่ด้วยชื่อไฟล์ ไม่ได้ดูจากเนื้อรูป

**3. ท่อน Style ห้ามแก้**
ทุก prompt มีท่อนเดียวกัน (ขอบนีออนม่วงหยดย้อย พื้นดำ ควันเรืองแสง เส้นขอบดำหนา)
นี่คือสิ่งเดียวที่ทำให้ 41 ใบเป็นชุดเดียวกัน ถ้าปล่อยให้ AI "ปรับให้สวยขึ้น" ทีละใบ
จะได้รูปสวย 41 ใบที่ไม่เข้ากันเลยสักคู่

**4. ห้ามวาดตัวการ์ตูนหรือโลโก้ของจริง**
Cookie Monster / Coco Chanel / KAWS — prompt เขียนไว้แล้วว่าเป็น**ตัวละครออกแบบใหม่**
อย่าปล่อยให้ AI วาดของจริง ผิดลิขสิทธิ์ ใช้กับร้านไม่ได้

## คำสั่งที่ต้องวาง / THE PROMPT TO PASTE

วางทั้งบล็อกนี้ใน ChatGPT พร้อมกับไฟล์ที่อัปโหลด

```
คุณกำลังช่วยร้าน Dank Cannabis Clinic (กรุงเทพ) ทำรูปสินค้าชุดใหม่
ให้เป็นสไตล์เดียวกับการ์ด "BOTANICAL LEGENDS" ของร้าน (ดูรูปตัวอย่าง 3 ใบที่แนบมา)

ไฟล์ที่แนบ:
- image-jobs.json = 41 รายการ แต่ละรายการมี prompt สำเร็จรูปแล้ว
- products.json   = แคตตาล็อกจริงของร้าน
- รูปการ์ดจริง 3 ใบ = สไตล์อ้างอิง ยึดตามนี้

งานที่ต้องทำ:

ขั้นที่ 1 — สร้างรูปทีละรายการจาก image-jobs.json
  · ใช้ค่าในช่อง "promptB_artOnly" เป็น prompt ห้ามเขียนใหม่ ห้ามย่อ
  · สัดส่วน 1:1 ขนาดอย่างน้อย 1024x1024 ส่งออกเป็น JPG
  · ในรูปต้อง "ไม่มีตัวอักษรใด ๆ" เลย ไม่มีชื่อ ไม่มีโลโก้ ไม่มีลายน้ำ
  · ตั้งชื่อไฟล์ตามช่อง "file" ของรายการนั้นเป๊ะ ๆ (เช่น crunch-berrie.jpg)
  · ทำทีละ 5 รายการแล้วหยุดให้ผมดูก่อน ถ้าผมบอก "ต่อ" ค่อยทำ 5 ถัดไป

ขั้นที่ 2 — ตรวจความเป็นชุดเดียวกัน
  หลังครบทุกใบ เอามาเรียงดูพร้อมกัน ใบไหนที่กรอบนีออน สีพื้น หรือน้ำหนักเส้น
  หลุดจากกลุ่ม ให้เจนใหม่เฉพาะใบนั้น อย่าปรับ prompt ของทั้งชุด

ขั้นที่ 3 — สินค้าที่ยังไม่มีในลิสต์
  เปิด https://dank-medical-pos-app.vercel.app/api/products
  หารายการที่ช่อง img ว่างหรือไม่มี แล้วสำหรับแต่ละตัว:
   ก. สร้าง prompt ใหม่ด้วยสูตรนี้ (เอาท่อน Style มาจาก promptB_artOnly ของรายการไหนก็ได้
      แบบก๊อปทั้งท่อน ห้ามพิมพ์เอง):

      Character artwork for the cannabis strain "<ชื่อสินค้า>". <ตัวละครที่คุณคิดขึ้น
      ให้เข้ากับชื่อและรสชาติ 1 ประโยค ระบุโทนสีด้วย>. <ท่อน Style ที่ก๊อปมา>
      NO text, NO letters, NO logo, NO watermark anywhere in the image —
      artwork only. Square 1:1 crop with the character centred.

      * ถ้าเป็นเบียร์หรือเครื่องดื่ม เปลี่ยน "cannabis strain" เป็น "the drink"
      * ถ้าเป็นขนม/vape เปลี่ยนเป็น "the cannabis product"
   ข. ตั้งชื่อไฟล์ = ชื่อสินค้าเป็นตัวพิมพ์เล็ก เว้นวรรคเป็นขีด ตัดอักขระพิเศษออก
      เช่น "Sour Belts 3000mg" -> sour-belts-3000mg.jpg
   ค. สรุปเป็นตารางให้ผม: ชื่อสินค้า | ชื่อไฟล์ | prompt ที่ใช้

ขั้นที่ 4 — ส่งกลับ
  · ไฟล์ JPG ทั้งหมด รวมเป็น zip ไฟล์เดียว
  · ตารางสรุป: ชื่อสินค้า | ชื่อไฟล์ | ทำแล้ว/ยังไม่ได้ทำ

ข้อห้าม:
  · ห้ามวาดตัวการ์ตูนหรือโลโก้ที่มีลิขสิทธิ์จริง — Cookie Monster, Coco Chanel,
    KAWS ใน prompt ระบุไว้แล้วว่าเป็นตัวละครออกแบบใหม่ ให้ยึดตามนั้น
  · ห้ามใส่ตัวหนังสือลงในรูป แม้แต่ชื่อสายพันธุ์
  · ห้ามแก้ท่อน Style ให้ "ดูดีขึ้น" เป็นรายใบ
  · ห้ามใส่รูปคนจริง โลโก้ร้านจริง หรือข้อความอวดสรรพคุณทางการแพทย์

ถ้ามีอะไรไม่ชัด ถามผมก่อน อย่าเดา
```

## ได้รูปมาแล้วทำยังไงต่อ / When the images come back

1. แตก zip → เอาไฟล์ทั้งหมดใส่โฟลเดอร์ `assets/products/`
2. รันคำสั่งนี้ (ดูก่อนว่าจะเปลี่ยนอะไรบ้าง ยังไม่เขียนจริง):
   ```
   node handoff/apply-images.mjs --dry
   ```
3. ถ้าถูกต้อง เขียนจริง:
   ```
   node handoff/apply-images.mjs
   ```
4. commit `products.json` + `assets/products/` → Vercel deploy เอง →
   **ติดทั้ง POS และเว็บลูกค้าพร้อมกัน** เพราะทั้งสองอ่านไฟล์เดียวกัน

สคริปต์แตะเฉพาะรายการที่หาไฟล์เจอจริงบนดิสก์ ดังนั้นทำครึ่งเดียวก็ปลอดภัย —
ตัวที่ยังไม่ได้วาดจะใช้รูปเดิมต่อไป ไม่กลายเป็นรูปแตก
และถ้าตั้งชื่อไฟล์ผิด สคริปต์จะเตือนว่า *"match no product id"* พร้อมบอกชื่อที่ผิด

> **ชื่อไฟล์ = ช่อง `id` ใน products.json** ไม่ใช่ชื่อสินค้า
> (`Zkittles` → `zkittles-top.jpg`, `Crispy Boy Lager Can` → `crispyboy.jpg`)
> ในนี้เคยมี 2 ไฟล์ที่ตั้งชื่อไม่ตรง id — เปลี่ยนให้ตรงแล้ว อย่าตั้งผิดซ้ำ

## เผื่ออยากเอาไปพัฒนาต่อทั้งระบบ / If you want ChatGPT on the whole app

ตัวแอปจริงคือไฟล์เดียว **`pos/app.fixed.jsx`** (~1.4MB) — ใหญ่เกินกว่าจะอัปโหลดตรง ๆ
ถ้าจะให้ ChatGPT แก้โค้ด บอกให้มันขอดูเฉพาะส่วนที่เกี่ยว แล้วพี่ค่อยตัดส่งไปทีละท่อน
รายละเอียดสถาปัตยกรรมทั้งหมดอยู่ใน **`CLAUDE.md`** — อัปโหลดไฟล์นั้นไฟล์เดียว
ChatGPT จะเข้าใจโครงสร้างทั้งระบบโดยไม่ต้องอ่านโค้ด 1.4MB
